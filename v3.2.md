### New in V3.2 (follow-up audit):
- [G1] **Toolchain pinning.** lerobot v2.0 format, MuJoCo, torch move faster than OpenVINO does. Two lockfiles: `requirements-cpu.lock` (WSL2 dev box) and `requirements-cuda.lock` (cloud GPU); `pip show` for hairline packages dumped to `output/env_snapshot.json` at Phase 0. Locks top out the "clean clone" claim.
- [G2] **Data-collection randomization policy fixed now.** Bootstrap set: nominal only (randomizer OFF, coupling=1) so data-quality failures isolate cleanly. If F7 escalation triggers, collect a second set with controlled pose/placement augmentation only, every episode tagged in `meta/info.json` (`random_profile`, `random_state`). The full 6-axis randomizer stays **eval-only**; eval seeds never collide with collected states.
- [G3] **Spoon AND fork coverage.** Challenge text lists both; V1.1 crafts fork only. `data/scripted_expert.py --item fork|spoon` reuses the identical 6-phase pipeline and target; optional `--item both` for episode variety. The planner treats the noun as a slot — no new logic, so "novel phrasing executes" stays honest.
- [G4] **One-command entry points.** Replace the multi-step runbook with exactly two scripts:
  - `scripts/run_dev.sh` (their box): install → verify → data → train → export → bench → eval → video.
  - `scripts/run_judge.sh` (Core Ultra 2/3): bare-Linux verify → download checkpoints → `benchmark_app` → `benchmark_intel.py` → `evaluate_seeds.py --use_coupling 0` → video. **Zero training.** One unmodified command; all three devices visible; README advertises only these two.
- [G5] **Single canonical eval CLI.** Remove `eval/eval_10_seeds.py`; keep only `benchmark/evaluate_seeds.py`. Any future wrapper must forward identical flags and is guarded by an interface test — two CLIs drift, and F3 dies quietly at drift.
- [G6] **Phase 1 gate re-leveled.** Hard blockers: oracle waypoints 10/10 + no QACC + mean err ≤ 0.05 rad. Target (reported, not gated): err ≈ 0.002 rad. A "~milliradian" gate invites tuning churn.

## 2. Architecture (Observe → Understand → Plan → Act → Optimize) — unchanged

```text
NL instruction + 3xRGB (contract per F4) + 14-DoF proprio
  → Planner (NL → APPROACH/OPEN/RETRIEVE/HANDOFF/PLACE/POUR + preconditions + re-plan; eval-only --perturb per F9)
  → SmolVLA finetuned (language+vision → chunks); router → ACT grasp ckpt if grasp_conf low
  → Coordinator (multiple roles, 0.05 m guard, mutex, clamps, e-stop; 20 Hz Sync → Async; max_steps ~300 + watchdog per F8)
  → MuJoCo dual-SO-101 scene (implicitfast@0.002×25, Kp15–55/Kv1.5–5.5, link mask, coupling gate, liquid proxy per F2)
  → Shared eval_scoring.py (F3) → split 10-seed scorecard + HUD
  → OpenVINO IR (FP16 + NNCF INT8, 100+ stratified cal per F5) via abstracted inference (CPU default, AUTO override)
```

- Liquid proxy honesty rule unchanged: deterministic kinematic channel only; README + video caption label it a proxy, never "fluid simulated".
- Perturbation honesty rule unchanged: `--perturb` is eval-only evidence of re-planning, never training data.
- Robustness honesty rule (new): the 6-axis randomizer is eval-only; any randomizer-ON training data must be the explicit G2-augmented set, tagged per episode.

## 6. Risks → mitigations (V3.1 + G#)

1. No Core Ultra → AUTO/CPU fallback, TBD columns, [F1][F6]; `run_judge.sh` rehearsed on a non-Ultra Linux box first (CPU-only mode) [G4].

3. Bimanual instability → implicitfast, gains, link mask, in-reach IK, guard + mutex + atomic transfer + clamps/e-stop + step cap [F8]; oracle before learned.
4. Grasp fail/overfit → coupling oracle-only; ACT fallback; paraphrases [G3]; broad eval-only randomizer [G2]; INT8 task eval [F5]; 7/10 gate; escalation [F7].
5. **Toolchain drift (lerobot/mujoco format)** → [G1] lockfiles + env_snapshot + verify asserts. **NEW**
6. **Judge dies mid-runbook** → [G4] single command, shipped pre-dry-run. **NEW**
7. **Data contamination / eval leak** → [G2] tags + eval seeds never overlap collected states. **NEW**
8. Unjudgeable pour → [F2] (unchanged).
